## 本輪改動

1. **冷灰公路＋暖燈識別**：重畫海岸出發、公路三連續路段、中繼站與冷窗夜車，同套 ink／gouache 前綴、上左光、粗輪廓。拿掉出發第二份標誌與浮貼北向箭頭，實體燈塔路牌接手方向；四種不同殘骸移動，144px 首尾疊合消除循環硬縫。
2. **人物真正落地**：熹的棕短髮、橙外套、琥珀圍巾由同一新 atlas 貫穿正側背、肖像、砲手、據點及通訊牌。兩敵種全動作重畫，藍工裝粗壯體與藍雨衣疾行體有不同剪影；手機以各幀 alpha 可見框維持存活主角／敵人寬高 >=40px。
3. **專屬 UI 與回饋**：焦邊行車紙、車票缺口主鍵、冷灰鋼片控制、固定淡燈塔光束。據點三個線圈改為三種實體誘餌裝置與生效暖光；夜車玻璃／行李架有霜痕、暖光及落塵，乘客／玻璃／屋頂可直接點選並走原觀察／反制規則。獲得補給數字有短補間，減動態設定保留真幀、關閉裝飾動畫。

手機的觸控說明在 R1 原始碼已修正，本輪驗證保留「按住左右轉向、點甩尾、自動射擊」，不把早已完成的修改重複列成新成果。
