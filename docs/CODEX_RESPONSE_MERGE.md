## 整合結果

三章、九個連續段落，席安與熹護送 A-07 和倖存者前往北方燈塔。日間開卡車、暮色佈誘餌守點、夜裡觀察與反制列車接觸，依序推進到同一個結局。沒有三原作選單或 iframe。開場一次點擊即進護航，正常護航 48 秒後接守點，再進列車；設計目標為前三分鐘玩到招牌、十分鐘內見到其他玩法，不把虛擬時鐘的自動操作當作真人完成時間。

只有補給可花費；救援人數提升守衛火力與黎明支援，據點補給供列車反制，車體／護具延續到下一章。護航救援與守點成果也帶來結算明示的維修。低車體需要及時清車，耗盡會失去動力並搶修重試；沒有測試專用無敵或通關路徑。每段 receipt 保護獎勵與維修，重開不重領。

單一 schema 1 存檔保留敵人、彈道、動畫、章節、資源、同行者、護具、判讀與夜間波次，重要操作／每秒保存，讀取有效備份，失敗明示並可匯出。行車簿共用暫停、返回封面、設定、匯出、還原與舊檔匯入。離開畫面會停止時間，回來手動繼續。原作的 JSON 與灰燼正式 Base64 匯出碼可主動封存、一次性換算補給；原文字／原始資料保留，不改寫三原作 storage keys，不把原作通關硬換成新主線。

三模式採同一行車票、色盤、字型、HUD、按鈕、燈塔圖示及本機合成音效。護航與據點使用公路、真幀敵人、車輛與路障；列車使用既有車廂與 A-07 真幀。來源 `snow.png` 實際是拖車內裝，已排除 runtime，唯讀快照保留在 vendor，沒有拿房間冒充據點。
