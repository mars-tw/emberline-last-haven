# 《燼途：最後一站》獨立美術審查 — 嚴格改善規格

> 審查依據：5 張 iPhone 實機截圖（`phone-01`～`phone-05`）＋同帳號其他 6 款遊戲定位比對。本工作區僅有截圖與題目檔，無原始工程／原始圖檔可查，故以下以截圖可見事證為準，不臆測程式內未呈現的素材。結論先說：**老闆說「美術很爛」是成立的**，而且 Apple 4.3 的判斷有具體畫面證據，不是誤判。

---

## 1. 總評

### 總分：**3.2 ／ 10**

| 面向 | 分數 | 一句話 |
|---|---|---|
| 構圖與畫面焦點 | 2.5 | 主角與車輛經常只佔畫面 15～25%，其餘是無資訊的暗色空地 |
| 色彩 | 3 | 深青外框＋米色卡＋膚橘按鈕從頭用到尾，遊戲內場景又是濁褐／濁黑，兩套顏色互相不認識 |
| 角色辨識度 | 2 | 主角在 1、3、4 圖縮到只剩一顆頭的色塊，64px 下無法辨識是誰 |
| UI 識別度 | 3 | 圓角矩形＋細描邊＋置中數字，就是通用後台／模板小遊戲外觀 |
| 美術風格一致性 | 2 | 白天俯視圖是粗糙貼紙風，第 5 圖夜間車廂卻是高密度精緻插畫，像兩款遊戲拼貼 |
| 與同帳號差異化 | 2.5 | 深藍綠 UI 外殼正是 4.3 最危險訊號，與其他款並排只換了標題字 |

### 最致命的 3 個問題（依嚴重度排序）

**致命傷一：沒有專屬視覺識別，外殼是「同帳號共用模板皮」→ 這是被 4.3 退件的直接原因。**
5 張圖的外殼 100% 相同：深青色底（約 `#1E3D44`）、左上圓形箭頭標誌、米色任務卡、膚橘色主按鈕、深青描邊次按鈕、頂部「補給／同行／車體／護具」四格數字列。這套版式拿去套在島嶼交通學院、三相邊境、裂潮卡牌上，只要換標題與數字就能成立。當一款末日護航遊戲與兒童交通、像素農場共用同一种「深青＋米卡＋橘按鈕」的後台感版式，審查員不需要玩，光看截圖並排就認定量產模板。**這不是「風格統一」，是「沒有為本作做設計」。**

**致命傷二：留白過多＋程序化方塊感，遊戲畫面本體是空的。**
第 1 圖遊戲區約 60% 是近乎純黑的無紋理空地；第 2～4 圖遊戲區是一條無限複製的柏油路貼圖，路緣兩側是同一塊污漬紋理平鋪，車道虛線等距、等長、等亮，一眼就是程序產生、沒有美術介入。第 3 圖更誇張：整條路只有 3 個橢圓線圈＋5 個「✕」符號就宣稱是一個守點場景。這種畫面在商店縮圖列表裡會直接被歸類為未完成品。

**致命傷三：風格斷裂＋比例崩壞，角色不存在。**
同一個主角：第 1 圖是跪坐的 Q 版小人（頭身比約 1:1.5），第 3、4 圖縮成站在「✕」上的一小坨，第 5 圖突然變成精緻的日系像素少女半身像，臉、髮、被褥、車廂木櫃全部高完成度。三種畫風、三種比例出現在同一款遊戲的前 3 個節點，玩家無法建立「這是我操控的那個人」的認知；美術部門的說法會是「素材來自不同外包／不同生成批次，未經統一樣式表收斂」。車輛亦同：第 1 圖的卡車是帶透視的立體車，第 2～4 圖變成純俯視貼圖，且與主角同框時大小關係每張都不同。

## 2. 逐張截圖診斷與改法

### 圖 1 — 出發（phone-01-departure.jpg）

**看到什麼問題**
- 遊戲區上半 2/3 是全黑漸層，只有一台車直立置中偏上、一個跪坐小人丟在左下角，兩者之間是大片死黑，沒有地面、沒有道路、沒有出城的敘事資訊。「南岸撤離線・首班出發」一行小字浮在黑上，像簡報註解。
- 車輛帶側面透視（看得到車側與車頂），人卻是正面跪坐，視角打架；車約佔遊戲區寬度 28%，但因為四周全黑，看起來像產品型錄貼圖，不是「即將出發的車隊」。
- 任務卡文字「把他們帶到有光的地方。」是全圖唯一有情緒的部分，但卡片是平塗米色＋細框，與下方黑場景零呼應。

**應該改成什麼**
- 構圖改為「低機位出發儀式」：車輛佔遊戲區寬度 **38～45%**、置於畫面下 1/3 黃金點，車頭朝上但帶 10～15° 斜角製造動勢；主角站在車門邊、高佔畫面 **18～22%**，與車形成大小對照，不要跪坐、要站立回望鏡頭或望向北方光源。
- 地面必須有資訊：下 1/3 是帶裂縫與灰燼的出城公路、散落行李與補給箱剪影，中景是熄滅的路燈與城牆輪廓，上 1/3 才留給夜空，且夜空要有北方一束微光（燈塔方向）作為全圖唯一高亮焦點。純色／近純色面積壓到 **30% 以下**。
- 色彩：地面用灰燼灰＋焦土褐，車輛暖燈是唯一暖色源，讓「有光的地方」在畫面上真的看得見光。

### 圖 2 — 白天護航（phone-02-convoy.jpg）

**看到什麼問題**
- 車永遠釘在畫面正中央偏下，道路紋理上下無限複製，兩側土黃污漬帶對稱平鋪，沒有路邊物件、沒有速度感，玩家看不出車在動，只看出貼圖在捲。
- 左側那隻「敵人」是一小團褐色糊影，與路面同色系，在真機尺寸下完全不可讀；「北方燈塔 ↑」文字＋箭頭浮在路面上，是 UI 貼紙不是場景路標。
- 48 秒／甩落 0 的計數與底部操作提示條都是半透明黑條壓在路上，與頂部米色卡三種底色打架。

**應該改成什麼**
- 車輛尺寸放大至遊戲區寬 **30～35%**，並允許左右偏移時車身帶 3～5° 傾斜與揚塵粒子；道路改為 **三段式捲動**：中央車道（裂縫、補丁、血跡拖痕隨機但不可等距）、兩側路肩每 3～5 秒出現一個可辨識物件（翻覆車殼、路牌、補給殘骸），製造前進證據。
- 敵人 sprite 至少要有輪廓光：深色身體＋一圈冷灰描邊，在褐色路面上 2 公尺外可辨識；尺寸不得小於車寬的 35%。
- 「北方燈塔」改為場景內的實體路牌或遠景光柱，不要用系統字浮在路上；計時與甩落數移入頂部資源列或做成車尾儀表造型，不要再壓半透明黑條。

### 圖 3 — 傍晚誘餌守點（phone-03-bait.jpg）

**看到什麼問題**
- 這是 5 張裡最空的一張：一條空路、3 個橢圓線圈（西／中央／東）、5 個木色「✕」，主角與車縮在最下緣幾乎被裁切。玩家完全看不出「屍群會從哪來、餌丟了會發生什麼」。
- 「✕」路障是扁平符號，與第 2 圖的寫實車輛貼圖不在同一個世界；橢圓投餌圈是簡報圖示，不是遊戲物件。
- 40 秒／誘開 0 掛在右上角，但畫面上沒有任何一隻敵人，倒數沒有對象。

**應該改成什麼**
- 場景要有「守點」的空間邏輯：下 1/4 是防線帶（路障要改成有體積的拒馬＋沙包＋車輛殘骸，佔寬各約 12～15%、高度可見），中段是三個投餌落點，落點不要用橢圓線，改用 **地面光圈＋餌料罐實體小圖**，丟餌後出現暖色光暈與氣味波紋；上 1/4 必須預覽屍群來襲方向（遠景黑影群＋塵土）。
- 主角與車回到防線中央、尺寸比照圖 2，不得縮到被裁切；「西／中央／東」文字縮小並貼附在落點下方，不要比角色還搶眼。
- 若本關就是做「下餌決策」，畫面至少要有一群敵人剪影正在接近，否則這張不能作為商店截圖。

### 圖 4 — 守點結果／共同進度（phone-04-common-progress.jpg）

**看到什麼問題**
- 敵人從上緣以相同姿勢、相同大小複製貼上往下掉，6 隻裡有 4 隻姿勢完全一致，且全部與路面同為褐黃色，糊成一團；中央那圈橘色橢圓壓在兩隻敵人身上，不知道是選取框還是命中特效。
- 主角站在「✕」正上方，像站在圖示上而不是防線後；車輛在右下角小到像道具。
- 這張與圖 3 用同一條路、同一排「✕」、同一個橢圓，兩張商店截圖並排會被認為是同一畫面截兩次。

**應該改成什麼**
- 敵人至少需要 **3 種體型／姿態**（疾行、踉蹌、攀爬）＋受擊／被餌吸引時的轉向與光暈回饋；同畫面複製同一姿勢不得超過 2 隻。
- 中央橘圈若為「誘餌生效範圍」，改為以餌料罐為圓心的半透明暖光圈＋向外波紋，且要讓敵人朝向改變看得出來；防線「✕」比照圖 3 改成實體拒馬。
- 與圖 3 的差異必須在構圖上拉開：圖 4 鏡頭應下移靠近防線、敵人佔比放大，呈現「撐住了」的密度感，而不是同一張路再加幾隻怪。

### 圖 5 — 夜間列車守夜（phone-05-night.jpg）

**看到什麼問題**
- 單張論，這是完成度最高的一張：車廂木櫃、吊燈、被褥、地圖、車窗外人影都有氛圍。但它與前 4 張 **完全不是同一款遊戲的畫風**：前段是粗糙俯視貼圖，這裡是精緻日系像素插畫，臉部與光影密度高出一個世代。玩家會懷疑前段是半成品、這張是外包範圖。
- 車窗外的威脅人影太美、太安靜，與「第 1／3 波・36 秒」的守夜壓力不匹配；主角躺床半身佔比雖大，但互動提示「頭頂傳來拖曳聲」與畫面中的車頂沒有視覺對應點。
- 即使是這張，外殼仍是同一套深青＋米卡模板，與車廂的暖木色毫無關係。

**應該改成什麼**
- 這張定為 **全作畫風錨點**：後續所有場景向它的光影邏輯靠攏——暖燈光源、木質與布料紋理、手繪感邊緣。反過來說，前 4 張必須重做至同一密度，不准再用扁平貼紙車與平鋪路面混充。
- 車窗外人影要加動態層：影子貼窗、緩慢移動、偶爾敲擊的震動線；「頭頂拖曳聲」要在車頂位置給一個可點的視覺熱區（行李架震動＋灰塵落下），不要只靠文字條宣告。
- 主角造型以此圖為準定版（棕短髮、藍綠上衣、臉型與眼睛畫法），並回頭重繪圖 1、3、4 的小尺寸版本，確保是同一個人縮小，而不是另一個小人。

## 3. 本作專屬視覺識別提案

> 設計原則：同帳號已佔用的語言一律避開——兒童交通的明亮原色與圓潤圖示、塔防的元素屬性色與格子盤面、卡牌的卡框與稀有度光效、像素農場的清新綠與方格田、3D 反詐的寫實劇情臉、Crackveil 的小隊陣形站位。本作要佔住一個別款沒有的位置：**「灰燼世界裡，靠一盞燈往北走」的公路守夜手記**。所有選擇從「車、燈、灰、路」長出來，不從通用遊戲 UI 長出來。

### 3.1 主色盤（7 色，全作不得再引入第二套主色邏輯）

| 色票 | HEX | 用途 |
|---|---|---|
| 燼灰底 Ash | `#2B2620` | 場景與外殼主底（取代現行深青；是燒過的木頭，不是科技藍綠） |
| 車廂木 Wood | `#5A4632` | 車輛、車廂、木質 UI 邊框、路障 |
| 燈塔琥珀 Lamp | `#E8A33D` | 唯一暖色焦點：車燈、燈塔光、餌料光暈、可互動提示 |
| 餘燼橘 Ember | `#C96F2E` | 主按鈕、警告、受擊回饋（比現行膚橘更沉、更像火） |
| 骨紙 Bone | `#E9DFC8` | 任務卡與手記紙面（保留米色但必須帶紙紋與焦邊，不得平塗） |
| 冷灰藍 Frost | `#7A8B8C` | 夜間、敵人輪廓光、次要資訊（冷色只作輔助，不得當外殼主色） |
| 血鏽 Rust | `#8C3B2E` | 危險、屍群、車體受損（低頻使用，出現即代表威脅） |

關鍵紀律：外殼主色從深青改為燼灰＋車廂木，**光是這一步就能與同帳號其他款的藍綠外殼拉開**；暖色（琥珀＋餘燼橘）在任何畫面中面積不得超過 15%，它只屬於「燈與火」，出現就代表希望或危險，不准拿來當裝飾漸層。

### 3.2 字體氣質

- **標題／任務名**：高對比的明朝／宋體氣質襯線體，筆畫帶一點粗糙邊緣，像用炭筆寫在手記上；字距略鬆、行高寬，呈現「寫給明天看的日記」。禁止再用圓體或粗黑體當標題——那是兒童款與後台款的語言。
- **內文／敘事**：同家族的較細襯線或帶人文感的黑體，16px 以上、行高 1.6，顏色用骨紙色壓在深底或深褐壓在骨紙上，確保閱讀像讀手記而非讀系統訊息。
- **數字／資源（補給、同行、車體）**：等寬或半等寬的「儀表字」，像車上的里程錶刻字；數字可維持大號，但字體必須與標題、內文分工，不得全作同一套無襯線到底。現行畫面所有文字（含數字）看起來是同一字體的三種大小，這是模板感主因之一。

### 3.3 UI 外框／按鈕造型語彙

- **外框語言：鉚釘鋼板＋焦邊手記紙。** 任務卡改為「撕邊／焦邊的紙」造型：邊緣不規則、帶一點燒灼痕、四角有膠帶或釘孔細節；遊戲畫面外框改為車體鋼板邊（細鉚釘點列＋磨損高光），讓畫面看起來是「透過車窗／行車紀錄器在看路」，而不是簡報的圓角投影片框。**全面禁用現在的「細線圓角矩形＋平塗底色」**，那就是後台語言。
- **主按鈕**：餘燼橘實心、形狀為「票券／車票」比例（寬長比約 3.2:1）、左側帶一個小齒孔或缺口細節，像撕下就能出發的車票；按下狀態要有像蓋章的下沉與邊緣亮起。次按鈕為木框線＋骨紙字，不得再與主按鈕只差底色。
- **資源列**：改為「行車儀表」橫列：每個資源有自己的小圖示（見 3.4），數字用儀表字，下方有細刻度線；車體百分比要有像油量錶的弧線或格數，不要只是「100%」三個字。
- **簽名元素（全作只押這一個，要做到看一眼就認出）**：畫面右上或任務卡一角固定有一道**北方燈塔光束的細長三角光**，隨章節進度改變角度與亮度，平時極淡、只在敘事提到燈塔時亮起。它是本作的商標，不要再加第二個裝飾母題。

### 3.4 圖示風格

- 手繪單線＋一個琥珀色光點：補給是罐頭、同行是牽手人形、車體是車側剪影、護具是盾形鉚釘牌，全部同線寬、同圓角邏輯，在深底上用骨紙線、琥珀點睛。禁止使用通用素材庫的扁平填充圖示，也禁止與兒童交通款共用圓潤粗線圖示。
- 敵人、餌料、路障等場景內物件圖示必須與場景 sprite 同畫風，不得用簡報橢圓與「✕」符號充當遊戲物件。

### 3.5 背景與角色美術風格（文字描述，不指名畫家）

- **背景**：厚塗帶手繪筆觸的末日公路——顏料感的天空與灰燼、路面有修補與拖痕、建築是燒毀後只剩骨架的剪影；光源永遠來自車燈或燈塔，採「大面積冷灰燼＋小面積暖燈」的對比，不要再平鋪單一污漬紋理當路肩。夜景向圖 5 的車廂密度看齊：木紋、布料、紙張都要有材質差異。
- **角色**：半寫實比例的少年／少女旅人（頭身比約 1:4.5，不要 Q 版 1:1.5 也不要日系大眼萌系），穿著有補丁的厚外套、圍巾以琥珀色作為個人識別色；臉部簡化但要有疲憊感（眼下陰影、沾灰），在小尺寸下靠「髮型輪廓＋琥珀圍巾」辨識，而不是靠臉。車輛是第二主角：鏽蝕、補焊鋼板、車頂行李與燈串，每台車有自己的傷痕，不得複製貼上。
- 一句話定版：**「燒過的世界、手繪的灰、只有燈是暖的」**——寫進外包樣式表第一頁，所有新圖先過這句話再談細節。

## 5. 驗收標準（可逐項打勾，不接受「感覺有變好」）

**識別度**
- [ ] 將本作 5 張新截圖與同帳號其他 6 款各 1 張截圖並排、遮住標題，3 位未參與開發的測試者中至少 2 位能在 5 秒內指出哪幾張屬於本作，且說得出靠什麼認（預期答案應包含：灰燼底色、琥珀燈光、焦邊紙卡、車票按鈕任一項）。
- [ ] 外殼主底色不得再出現現行深青色系（色碼與 `#1E3D44` 的色差 ΔE 需明顯可辨）；若新圖與任一款舊作並排仍被說「像同一家模板換皮」，直接退回重做外框與按鈕，不得只換主色了事。

**縮圖與角色**
- [ ] 主角 sprite 縮至 **64px 高** 時，仍可憑髮型輪廓＋琥珀圍巾辨識為主角（與路人／同行者並排盲測，辨識率 ≥ 80%）。
- [ ] 主車縮至商店列表縮圖寬度（約 180px）時，車頂行李、燈串、鏽蝕三項特徵至少可見 2 項；敵人 sprite 在真機尺寸、2 公尺遊戲距離外可辨識輪廓，不得與路面糊成一團。

**畫面密度與構圖**
- [ ] 任一遊戲畫面中，近純色／無紋理空白面積 **≤ 30%**（以截圖像素統計，單一色值±5% 連續區域計入）；圖 1 類型的「黑空地＋中央貼一台車」構圖直接不合格。

**風格一致性**
- [ ] 隨機抽 3 個節點截圖（出發／守點／守夜），主角臉型、圍巾色、車輛傷痕位置必須一致；若任一張被測試者說「像不同遊戲的圖」，整批退回，不接受單張修補。
- [ ] 全作暖色（琥珀＋餘燼橘）單畫面面積 ≤ 15%，且只出現在燈、火、餌、可互動提示四類物件上；出現無意義的暖色漸層裝飾即退回。

**UI 與文字**
- [ ] 任務卡具備焦邊／撕邊紙紋與至少一處固定細節（膠帶、釘孔或燒痕），按鈕具備車票缺口或等效造型；若只換顏色、形狀仍是細線圓角矩形，視同未改版。
