# 燼途：最後一站｜整合設計

Emberline: Last Haven，0.1.0。本機原生整合，Vite＋TypeScript＋Canvas 2D，無 iframe。三原作轉為一條連續北上旅程，玩家只有「接下北上任務」及之後的繼續入口。

## 世界、人物與主線

灰燼災變後，南岸失去補給。席安駕駛裝甲卡車，熹照看拖車與補給，A-07 隨車隊北上，途中向同伴說出名字「安」。目標是將倖存者與燃料送到仍在發訊的北方燈塔。敵群依聲音與氣味追蹤，不是三種互不相關的世界設定。

| 章節 | 日間護航 | 暮色守點 | 列車守夜與轉折 |
|---|---|---|---|
| 灰燼出城 | 南岸公路，接走沿路倖存者 | 雪線中繼站，用誘餌守住轉運區 | 灰霧鐵道，觀察安與冷窗，封存交接判讀，得知她的名字 |
| 白霜斷橋 | 繞過斷橋，救援守燈人車隊 | 冷庫據點，保存裝車補給 | 白霜支線，安看見海岸，守衛成為同車旅伴 |
| 燈塔之前 | 海岸撤離線，接走最後一批人 | 最後補給站，撐到列車開動 | 燈塔終站，安接上廣播，倖存者成為下一班車的守燈人 |

三章目前共用同一套公路／雪地／車廂畫；第二、三章增加敵人耐久與累積的隊伍後果，沒有假稱九張獨立新地圖。章節差異還需要專用原畫、特殊危機與真人平衡驗證。

## 前三分鐘與十分鐘

開場已交代燈塔任務，按一次「接下北上任務」即操舵。第一隻敵人開局出現，靠近車身後攀附；玩家可左右操舵、自動射擊、等兩隻後甩尾並得到連鎖補給。正常首段最快 48 秒，若沒有完成甩尾則 78 秒抵達且救援較少；車體耗盡會中止，需搶修重試，不是無敵教學。抵達後人員數立刻增加守衛火力，主線的下一步只能前往中繼站。守點需 40 秒且真實誘開兩隻，失敗佈局可延至 60 秒。之後同一份補給支付列車反制。

正常路徑約兩分鐘可進列車；前三分鐘與十分鐘目標是設計節奏，不拿虛擬時鐘的自動操作當真人完成時間。11 視口與兩引擎測試只證明操作路徑可達。

## 共用狀態與成長

只有「補給」可花費。同行人數、車體、護具是同一旅程的狀態，不是三套貨幣。護航每兩隻甩落提高救援成果；同行者成為守點火力 `1 + floor(people / 3) + level`，也成為列車乘客與黎明維修支援。守點以 1 補給投餌，完成的誘敵數提高回收補給；列車正確反制花 2，免費伏低會受損。正確反制、同行人數及護具影響黎明恢復與後段可用資源。三章結算各有唯一 receipt，重開不重領。

段落結算可花 4 補給整備護具，最多三級：增加火力、降低啃咬及承受傷害、修復車體、延長後續預警。這是跨模式成長，不另設三棵技能樹。

救援者也會維修：護航結算每位新救援者修 3％車體，據點結算由同行者修 `6 + floor(people / 2)`％，黎明修 `5 + people`％，皆上限 100％。修復數直接寫在結算與 HUD；同一 receipt 不能再修或重領。這讓救援與守點成果能支撐後續章節，同時保留段內真正失去動力及搶修重試的風險。

## 存檔與舊玩家

單一 schema 1 存檔 `emberline.campaign.v1`，保留有效上一版 `.backup`；保存章節、段落、敵人／彈道／動畫時間、車體、補給、同行者、護具、判讀、波次與一次性結算。每秒及操作後同步落盤，重開先顯示手動繼續。存檔失敗明示「尚未保存」，可匯出。資料損壞優先有效備份，不直接刪除原 key。

舊玩家主動選擇來源與檔案後才能匯入；灰燼接受原始 JSON 及原作 UTF-8 Base64 匯出代碼（.txt），暴風／夜行接受 JSON。驗證來源結構，每原作最多一次，給 2–12 補給並封存完整原始資料。灰燼保留 parts／bestWave／totalRuns 及其餘收藏，Base64 另保留原文字；暴風保留 wave／money，夜行保留 day／route／resources；不把原作不同關卡硬換成整合主線通關。原作解鎖、收藏與劇情仍在原作，來源檔與原 storage keys 不寫入。跨網域、WKWebView 沙盒與 IndexedDB 無法由新網站直接讀取；原始 App 若沒有匯出，匯入前置流程 **BLOCKED**，須後續在獲授權原生版本提供匯出或同 Bundle 遷移。本輪不改來源補接口。

## 外觀、操作與資產

色票：深海灰 `#243e46`、紙票 `#e8d9b8`、銅棕 `#d69a6f`、海霧 `#a8c9c6`、灰線 `#81908a`。章節票根是唯一視覺標記，標題用裝置楷體，內文為正黑體，數字為 monospace。三模式共用 HUD、行程、提示、按鈕、設定、暫停／返回、存檔狀態、燈塔圖示與三角波音效；音效可關，無音訊裝置仍可玩。

暴風的 3D 肉舖呈現改為灰燼世界的 2D 雪地中繼站，保留三落點改變追蹤目標，取消原作獨立金錢與商店。夜行保留觀察呼吸／冷窗與判讀原引擎，A-07 用真正 listen／startle 幀；原作 UI、農耕、配電與三線七夜長篇不移植。灰燼保留攀附槽、穿甲、甩動、冷卻、甩飛連鎖與真幀敵人，省去四環境、拖車家具、各自收藏與原教學。

來源不完整的攀車專用動作仍缺，當前使用真 attack 動作，不把這叫完成攀車圖集。部分公路／車廂明度偏暗，未重製三視圖與完整色彩閘。兩個人物畫風已有共用色調與 UI，但專用美術統整仍需後續製作，風險不因外殼消失。

## 技術邊界與後續

原生 Canvas 引擎統一世界座標與輸入、上層統一狀態機；只保留必要來源純規則與夜行觀察引擎。來源原碼保存在 vendor 作回歸，執行期只載入實際使用的 ESM，沒有隱藏三套選單。當前夜行原引擎樹仍約 334 KB bundle，後續可抽離純 handover／threat 決策及縮減相依，不修改本輪保留的來源測試。新美術、原作其餘內容不是「已移植」；未來採同一 Campaign API 擴充章節，不能重新塞回原作入口。

正式靜態包 build 時雜湊完整檔案清單，SW cache 一個 revision 並僅刪本作舊 revision。所有素材、字型與音效均無遠端依賴。橫直與 iPad 的世界／碰撞固定座標，不隨 CSS 比例變更。背景暫停、觸控取消與同一行車簿全模式生效。實機切背景、音效、原生容器安全區與簽章包仍需驗收。
