# 隱私與發行資料草稿｜PREPARED

本機 web repo 沒有帳號、分析、追蹤、廣告、內購、後端或上傳介面。只向同來源取得靜態遊戲檔，SW 用於離線；音效由 Web Audio 本機合成，字型使用裝置字型。

行車紀錄、備份、原作封存與設定儲存在裝置 localStorage。匯入只讀使用者主動選取的 JSON／灰燼匯出代碼，保存在同一旅程內；匯出只產生本機下載。程式沒有把檔案或紀錄傳到任何伺服器。讀取匯入檔的上限是 250 KB，重複原作不重領補給。

這是網頁程式範圍的資料流程說明，不是最終 App Store 隱私標籤或 Google Data Safety 的正式宣告。後續原生容器、SDK、UserDefaults 使用理由、簽章 archive 與實機網路紀錄需重新核對。公開政策 URL、支援信箱與負責者資料尚缺；本輪沒有部署一個假公開網址，也沒有操作商店。
