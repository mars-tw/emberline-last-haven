## 說明

白天，開卡車把公路上的人接走。
暮色，讓屍群追著誘餌，守住轉運據點。
夜裡，看清冷窗與車頂的訊號，把同一隊人送到下一站。

南岸失去補給，北方燈塔還在發訊。你與席安、熹和乘客 A-07 沿著撤離線北上，經過灰燼出城、白霜斷橋與燈塔之前三章。九個連續段落，共用一份行車紀錄。

卡車上的敵人不是只能射掉。讓牠們攀車，再用甩尾清車；一起甩落的連鎖會回收補給。救回的人，下一段會成為據點守衛與列車乘客。

據點有西側、中央與東側三個投餌位置。每份誘餌都來自你剛帶回的補給；多花一份引開敵人，列車上就少一份可以反制的物資。

登車後，先觀察安的呼吸與冷窗，再封存你的判讀。判對首波會多些預警，判錯就得更快反應。百葉對付窗側敲擊，扣具處理車頂攀附；也可以讓大家伏低，承受車體損傷。

整備護具會影響整趟旅程的火力與生存。離開畫面即暫停，回來手動接著走。首次連線完成離線快取後，可離線遊玩；進度保存在裝置，也可以匯出 JSON。若有三個原作的 JSON 存檔，可選擇封存舊進度並換取一次補給；原作的劇情與收藏不會被換算成新主線通關。
